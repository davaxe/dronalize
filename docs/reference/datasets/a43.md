# A43

A43 is a drone-recorded highway trajectory dataset from Germany. It focuses on naturalistic vehicle motion around an off-ramp and congested highway segment, making it a useful reference for lane-level traffic analysis and motion forecasting.

## Default prediction task

The `benchmark` prediction task is selected automatically. In the project config, select it explicitly with `task = "benchmark"` or disable prediction bounds with `task = "none"`.

| Setting | Default |
| ------- | ------- |
| Configured horizon | 70 frames (benchmark origin 20) @ 10.0 Hz |
| Effective horizon | 70 frames (benchmark origin 20) @ 10.0 Hz |
| Source unit | Recording |
| Source bounds | 1353-50814 frames (observed) |
| Resampling | None |
| Sliding windows | Enabled, strict, step 25 |
| Screening | Prune agents with fewer than 2 observations |
| Maps | Full map |

### Map types

| Dataset type | Prejectory type |
| ------------ | -------------- |
| Reconstructed outer lane marking | `ROAD_BORDER` |
